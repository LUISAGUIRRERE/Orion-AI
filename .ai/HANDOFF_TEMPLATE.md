# Handoff Template

Use this template when handing off work between AI Board members, or between sessions with the same member. Copy it into the relevant Issue, Pull Request, or session note.

## When a Handoff Is Mandatory

A handoff is mandatory when:

1. Work passes from one AI Board role to another.
2. A session ends with incomplete work.
3. A Pull Request requires rework by a different role.
4. A decision or unresolved risk must be carried into a later session.
5. Responsibility for the next action changes.

## Template

```
## Handoff

**Date:**
**From:**
**To:**

### Context
What is this handoff about, and why is it happening now?

### What Changed / What Was Done
Summary of work completed so far.

### Related Links
- Issue:
- Pull Request:
- ADR (docs/DECISIONS.md):

### Current State
Where things stand right now.

### Open Questions
Anything unresolved that the receiving party needs to decide or clarify.

### Next Steps
What should happen next, and who is expected to do it.

### Risks / Blockers
Anything that could stall or derail the next steps.
```
